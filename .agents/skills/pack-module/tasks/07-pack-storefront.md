# Task 07 — Pack Storefront

Integrate Pack listing/detail/variants/cart into existing React storefront patterns.

Requirements:
- Consume backend Pack APIs and calculated availability.
- Show Pack price, compare-at price, discount, images, variants, availability, low-stock state where appropriate.
- Disable unavailable variants and add-to-cart for unavailable Pack.
- Cart quantity is validated by backend; frontend stock is informational only.
- Checkout revalidates authoritative stock.
- Preserve existing Product UX and prevent regression.
- Do not calculate authoritative stock in frontend or create a separate Pack cart.

Implement frontend tests and relevant integration tests. Execute and report.
