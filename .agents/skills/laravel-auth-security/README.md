# Laravel Auth Security Codex Skill

## Install in a repository
Copy the `laravel-auth-security/` directory into:
`.agents/skills/laravel-auth-security/`

Expected:
```
.agents/skills/laravel-auth-security/
├── SKILL.md
├── references/
└── templates/
```

## Invoke in Codex
```
$laravel-auth-security Audit admin/customer authentication. Do not modify files.
```
or
```
$laravel-auth-security Implement the approved isolation design. Follow all phases, tests, and reporting.
```

Start with audit-only unless implementation is explicitly requested. Read `SKILL.md` before proceeding.
